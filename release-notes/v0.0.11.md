36 merges since v0.0.10. The headline: invariant checks compile to SQL, and admission is case-local.

## Upgrading

- Run `morpholog migrate`. Four migrations are new: claims keyed by a digest of their arguments (long arguments no longer hit PostgreSQL's index row limit), checkpoint witnesses, audit rows that name their own parameters, and a registry for the indexes the compiled checks use.
- Then run `morpholog provision indexes <file.morph>` for each programme. `check -v` says whether a programme's invariants compile.

## What changed in how a change is admitted

- **Admission is case-local** (#364, #365). An invariant still says what lawful records look like. When a change is proposed, Morpholog rechecks every case the change touches; a violation already sitting in history elsewhere no longer blocks unrelated changes. A change that touches a broken case without repairing it is still refused. The audit row's `invariants_checked` keeps its meaning. `docs/runtime-semantics.md` has the full rule.
- **Invariant checks compile to SQL** (#315, #343, #348, #353). Where every invariant of a programme compiles, a proposal checks them inside its own transaction, bounded to the cases it touches. The in-memory kernel stays the specification; a differential test holds the SQL path to it.

## Performance

- On the compiled route with its indexes provisioned, one ledger posting takes 7-9 ms at 1,000, 10,000 and 100,000 entries (it grew linearly before). Sixteen writers on one shared key retry 0.72 times per commit, against 11 before (#363, #366).
- Candidate states share their pre-state instead of copying it, and replays advance one state in place (#340, #341).

## For embedders

- **`transact`**: several proposals as one decision - all commit or none do (#331).
- **Self-describing audit rows**: each row written from migration 014 on names its transformation's parameters, so that history reads correctly after the programme changes; older rows keep none (#332).
- **Witnessed checkpoints**: an RFC 3161 timestamp authority can countersign a checkpoint, and the verifiers judge it (#328).
- **Verifier-pinned signing keys** (`--require-signing-key`, `--require-signatures-from`) (#325), and `check --against` reports programmes that write the same predicates (#326).
- A database error before the decision is now a known non-commit, not an unknown outcome (#329). Batch error receipts carry the session's stable error code (#324).
- Operational timestamps are `jiff` throughout the adapter, with one wire spelling (#339, #368). The audit tail no longer waits on autovacuum (#369).
- The public Rust API is a committed snapshot under `api/`, hidden items included (#367, #374).

## The instrument

- `morpholog-bench --implementation interpreted|compiled|compiled-indexed`, a `compare` that says whether runs separate, and `scripts/bench_ab.sh` for interleaved baseline-against-candidate runs (#342, #363, #370, #371).
